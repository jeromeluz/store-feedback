# 區組回饋平台 快速登入更新

管理者登入畫面新增「快速登入」按鈕。點選後輸入 4302，若目前瀏覽器已有 Firebase 保留的管理員登入狀態且 admins/{UID} 的 enabled 為 true，就直接進入後台。

第一次在新裝置使用時，仍需以 Email 與密碼手動登入一次。手動登出、改以門市身分登入、清除瀏覽器網站資料、登入狀態失效後，都需要重新手動登入。4302 僅為介面確認碼，不是伺服器端身分驗證。管理員密碼沒有寫入網頁。

請將 index.html、app.js 更新到 GitHub Pages 專案根目錄。config.js 與 Firestore 規則不用更動。部署後重新整理頁面。

尚未在實際 Firebase 線上環境測試。
