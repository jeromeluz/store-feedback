# 區組回饋平台 V23 — 轉店店號確認版

## 更新內容
- 依使用者確認結果，將 19 組同名轉店資料各排除 1 個舊店號，保留指定的正確店號。
- 門市名冊由 813 筆調整為 **794 筆**，10 個區課維持不變；名冊內已沒有重複店名。
- 門市可繼續使用店名或店號登入，管理員仍可依區課選擇門市。
- 保留 V22 的同名門市確認機制，以防未來名冊又出現重名。

## GitHub Pages 部署
請將 `index.html`、`app.js`、`store-catalog.json` 三個檔案一起更新到 GitHub 根目錄，避免瀏覽器快取舊名冊。其他檔案可維持原版。

## 重要：既有 Firebase 資料不會自動改動
此次只更新可選門市名冊，不會刪除 Firestore 已建立的門市、回饋、照片或任務。若舊店號已在 Firebase 建立門市，需另外進行資料對應與移轉，避免舊店號仍能登入或既有回饋遺失。
