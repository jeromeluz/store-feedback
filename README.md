# 區組回饋平台 V21 — Excel 門市名冊版

## 更新
- 門市名冊取自使用者提供的 Excel，共 **813 筆**、**10 個區課**，已內建在 `store-catalog.json`
- 管理員「門市管理 → 從門市名冊新增」開啟彈出視窗，先選區課再搜尋門市名稱或店號，點選即新增
- 門市列表、門市端標題、任務指定門市與回饋匯出顯示 `門市名稱(店號)`
- 門市端輸入 **門市名稱或店號** 登入，登入成功記住店號
- Excel 中存在同名不同店號的門市，這些門市需以店號登入，避免誤認
- 已有舊門市資料保留；舊門市仍可登入。新名冊門市使用固定店號，不能任意改名

## 部署（重要）
1. 更新 GitHub Pages 根目錄 `index.html`、`app.js`、`store-catalog.json`
2. 到 Firebase Console → Firestore Database → Rules 發布本包 `firestore.rules`，否則店號登入與新增門市會出現權限錯誤
3. 確認管理員可從區課選擇門市並新增，門市端可用店號登入

## 注意
- 名冊只提供可選項目，不會一次建立 813 間門市；每位管理員仍需自行選擇自己的門市
- 原本已建立的舊門市不會自動變更店號；如要與 Excel 對應，建議先備份回饋並另行做安全資料移轉，不要直接刪除舊門市
- 店名重複時，系統會要求用店號登入。不同管理員不可使用同一個店號
- 不需要上傳 Excel 到 GitHub，系統讀取的是產生的 JSON 名冊


## V22 同名門市登入確認
輸入店名如有多間同名門市，彈出視窗列出 Excel 名冊中的區課、店名及店號。選定後按店號既有流程登入；未被管理員新增的店號仍不能登入。輸入店號或唯一店名維持直接登入。更新 GitHub 的 index.html、app.js；store-catalog.json 沿用 V21。Firebase 規則不需更改。
